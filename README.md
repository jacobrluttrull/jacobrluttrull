## Selected Projects

### **Portfolio Website** — Full-Stack Personal Site
Full-stack portfolio site built with FastAPI and PostgreSQL, deployed on Railway. Features a JWT-protected admin panel for managing projects, a contact form with XSS sanitization, CSRF protection, Cloudinary image uploads, and a responsive frontend. I recently updated and refined this project as part of my ongoing backend and deployment work.

- Live: [jacobrluttrull.com](https://jacobrluttrull.com)
- GitHub: [jacobrluttrull/portfolio](https://github.com/jacobrluttrull/portfolio)

### **Gator** — CLI RSS Feed Aggregator
CLI RSS feed aggregator built in Go and backed by PostgreSQL. Users can register and log in, add and follow RSS feeds, unfollow feeds, list available feeds, fetch posts from subscribed sources, bookmark posts, and search across followed content. I recently expanded the project with a clearer CLI/API split, richer documentation, bookmarking, and a more complete aggregation workflow.

- GitHub: [jacobrluttrull/gator](https://github.com/jacobrluttrull/gator)

### **Diabetic Prediction Website** — Diabetes Risk Prediction App
Machine learning application using XGBoost and scikit-learn to predict Type 2 diabetes risk with ~80% accuracy. Includes an interactive Streamlit web app with SHAP visualizations for explainable predictions.

- GitHub: [jacobrluttrull/prod-diabetic-capstone](https://github.com/jacobrluttrull/prod-diabetic-capstone)

### **Oklahoma Sooners Dashboard** — College Football Statistics Dashboard
Full-stack Django web app integrating the CollegeFootballData (CFBD) API to surface season records, rankings context, player leaders, a ranked schedule, and live game box scores. Normalized relational data powers the stats and browsing experience.

- GitHub: [jacobrluttrull/oklahoma_sooners_dashboard](https://github.com/jacobrluttrull/oklahoma_sooners_dashboard)

### **Pokedex CLI** — Command-Line Pokedex in Go
REPL-based Pokedex built in Go using the PokéAPI. Features location exploration, Pokemon encounters, a turn-based battle system, multiple pokeball types with different catch rates, nickname and release mechanics, and persistent exploration state.

- GitHub: [jacobrluttrull/pokedex](https://github.com/jacobrluttrull/pokedex)

### **Static Site Generator** — Custom Markdown-to-HTML Generator
Python-based static site generator built from scratch that converts Markdown content into a fully static HTML/CSS website. Features recursive directory traversal, a custom Markdown parser, and output generation for nested content.

- Live Demo: [jacobrluttrull.github.io/static_site_generator](https://jacobrluttrull.github.io/static_site_generator/)
- GitHub: [jacobrluttrull/static_site_generator](https://github.com/jacobrluttrull/static_site_generator)

### **AI_Bot** — Tool-Using AI Coding Agent (REPL + Function Calling)
Python-based CLI AI assistant using the OpenAI API with function calling and a multi-step agent loop. Supports one-shot prompts and an interactive REPL mode, with tools for listing files, reading/writing content, and iterating on code.

- GitHub: [jacobrluttrull/AI_Bot](https://github.com/jacobrluttrull/AI_Bot)

### **python_git** — Build Your Own Git (Python)
Hands-on implementation of core Git internals in Python, exploring how version control works under the hood.

- GitHub: [jacobrluttrull/python_git](https://github.com/jacobrluttrull/python_git)
